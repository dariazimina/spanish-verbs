# Spanish Verbs A1–A2 — PWA

Это автономное веб-приложение (PWA), которое можно установить на Android через Chrome.

## Как запустить
Нужен HTTPS-хостинг или localhost. Самый простой вариант — GitHub Pages:
1. Создать репозиторий на GitHub.
2. Загрузить содержимое этой папки.
3. В Settings → Pages включить публикацию из ветки main.
4. Открыть получившийся HTTPS-адрес в Chrome на Android.
5. Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

После первой загрузки основные файлы кэшируются Service Worker и приложение работает без интернета.

## Важно
При обновлении файлов нужно увеличить CACHE в sw.js (например v2), чтобы телефон получил новую версию.
