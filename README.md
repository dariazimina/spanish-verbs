# Spanish Verbs A1–A2 — PWA

Это автономное веб-приложение (PWA) для тренировки испанских глаголов A1–A2. Его можно установить на Android и iPhone как веб-приложение.

## Как запустить
Нужен HTTPS-хостинг или localhost. Самый простой вариант — GitHub Pages:
1. Создать репозиторий на GitHub.
2. Загрузить содержимое этой папки.
3. В Settings → Pages включить публикацию из ветки main.
4. Открыть HTTPS-адрес приложения.

### Android
Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».

### iPhone
Открыть приложение в Safari → «Поделиться» → «На экран Домой» → включить «Открывать как веб-приложение» → «Добавить».

После первой загрузки основные файлы кэшируются Service Worker и приложение может работать без интернета.

## Обновления
При обновлении приложения увеличивайте номер CACHE в `sw.js`. В версии v8 старые кэши автоматически удаляются при активации нового Service Worker.
